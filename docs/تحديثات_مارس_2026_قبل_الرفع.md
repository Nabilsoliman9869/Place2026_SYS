# تحديثات مارس 2026 — مراجعة قبل الرفع

## 1. تغييرات قاعدة البيانات (Schema)

### ClientRequests
- **عمود جديد:** `AllocatorRole` (NVARCHAR 100) — المخول بالترشيح لطلب العميل
- **Migration تلقائي:** يُضاف عند بدء التطبيق عبر `init_system()` إذا لم يكن موجوداً

### Candidates
- **RecruiterFeedback:** يُضاف تلقائياً إذا لم يكن موجوداً (من سكربتات سابقة أو init_system)

### التحقق
- عند أول تشغيل بعد الرفع، `init_system()` يُنفّذ migrations تلقائياً
- إذا ظهر خطأ "AllocatorRole غير موجود" عند إنشاء طلب عميل: إعادة تشغيل التطبيق

---

## 2. نقاط تم مراجعتها

| البند | الحالة |
|-------|--------|
| AllocatorRole في INSERT | تم إضافة try/except مع رسالة واضحة عند فشل schema |
| RecruiterFeedback في profile | تم تمريره من backend (cand.get) تجنباً لأخطاء عمود مفقود |
| migration RecruiterFeedback | تم إضافته في init_system لجدول Candidates |
| API البحث `/api/candidates/search` | محمي بـ login_required، استعلامات parameterized (لا SQL injection) |
| فلترة التدريب (context=training) | تعمل مع PrimaryIntent و Status |
| allocation_confirm_match | يتحقق من AllocatorRole قبل الترشيح، يعرض "ليس لديك الصلاحية" |

# النقطة المستقرة قبل التعديلات — آذار 2026

**هذا الملف يوثّق المرحلة الحالية من النظام كمستقرة قبل تنفيذ التعديلات التالية.**

التعديلات المخطط لها (لم تُنفّذ بعد):
1. تكوين الدفعة: الوقت من–إلى، أيام الأسبوع، أيام الامتحانات الدورية
2. سجل الحضور: قوانين التأخير والغياب والحساب التلقائي
3. مختبر مواهب: شاشة حجز مواعيد لنفسه + زر فيدباك في أيام الامتحانات
4. إضافة يوزر SALMA بصلاحيات مبيعات+منسق

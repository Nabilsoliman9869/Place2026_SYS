## نوافذ وحقول مركز المطابقة

### 1. Matching by Request (عميل → طلب عميل → ترشيح)

| الحقل | الاسم بالعربية | النوع | الوصف |
|------|----------------|-------|-------|
| Client | العميل | قائمة منسدلة | اختيار الشركة (Company) |
| Job Order | طلب العميل | قائمة منسدلة | الطلبات المفتوحة للعميل المختار |
| Apply | تطبيق | زر | إرسال الفلاتر وعرض المرشحين |

**تسلسل العمل:** اختر العميل → اختر الطلب → اضغط تطبيق (أو يتطبق تلقائياً عند الاختيار).

---

### 2. Matching Candidates (المرشحون المطابقون)

يظهر بعد اختيار عميل وطلب.

| العمود | الوصف |
|--------|-------|
| Candidate | اسم المرشح، هاتف، جنس |
| Level | المستوى CEFR |
| Score | درجة التطابق (+ فوق الحد، Exact مطابق بالضبط) |
| Action | زر **Allocate / ترشيح** |

**نافذة التأكيد (Modal):**
- Notes | ملاحظات: نص حر
- Feedback for Recruiter | ملاحظات للريكروتر: نص حر
- Confirm | تأكيد

**قاعدة:** المرشح الواحد لا يزيد عن ترشيحين نشطين. عند تجاوز الحد يظهر تنبيه: "يجب تسجيل رفض في أحد المقابلات أولاً لتحرير الشاغر".

---

### 3. Approved Matches (Action: Schedule Interview)

الترشيحات المُقبَلة التي تحتاج جدولة مقابلة.

| العمود | الوصف |
|--------|-------|
| Candidate | المرشح، هاتف |
| Job Order | عنوان الوظيفة |
| Company | الشركة |
| Status | Approved |
| Action | زر **Set Date** |

**نافذة جدولة المقابلة:**
- Date | التاريخ: نوع date
- Time | الوقت: نوع time
- Save & Notify Recruiter | حفظ وإشعار الريكروتر

---

### 4. AI Suggested Matches (Smart Matches)

مقترحات ذكية بناءً على المطابقة التلقائية.

| العمود | الوصف |
|--------|-------|
| Candidate | المرشح، الجنس، الهاتف |
| Current Level | CEFR الحالي |
| Matched Job | الطلب المقترح |
| Required Level | الحد الأدنى المطلوب |
| Client | العميل |
| Score | Perfect / Good / Exact |
| Action | زر **Review & Approve** |

**نافذة المراجعة:** تعرض بيانات الوظيفة والمرشح + Notes + Feedback + Confirm.

## وظيفة كل جزء من شاشة مركز المطابقة

| الجزء | الوظيفة |
|-------|---------|
| **قواعد الترشيح** | يشرح شروط وحدود الترشيح (مثلاً: حد ترشيحين نشطين للمرشح) |
| **Proposed Matches Found** | عدد اقتراحات المطابقة الذكية التي أنشأها النظام |
| **Matching by Request** | فلترة المرشحين: اختر العميل ثم الطلب، ثم **تطبيق** لعرض المرشحين المطابقين فقط |
| **Client / العميل** | قائمة الشركات — اختر الشركة أولاً |
| **Job Order / طلب العميل** | قائمة الطلبات المفتوحة للعميل المختار |
| **Matching Candidates** | جدول المرشحين المطابقين للطلب — زر **Allocate** لترشيح كل مرشح |
| **Approved Matches** | المرشحون المُقبَلون الذين يحتاجون جدولة مقابلة — زر **Set Date** لتحديد موعد المقابلة |
| **AI Suggested Matches** | اقتراحات النظام للمطابقة — زر **Review & Approve** لمراجعة والموافقة |

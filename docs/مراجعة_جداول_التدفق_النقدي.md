# مراجعة جداول التدفق النقدي (Smart CashFlow)

## الجداول المستخدمة

| الجدول | الوظيفة | الحقول الرئيسية |
|--------|---------|------------------|
| **TBL004** | دليل الحسابات الفرعية | CardGuide, AccountName, CardCode, MainAccount |
| **TBL009** | أنواع القيود (قبض/صرف/قيد) | CardGuide, EntryName |
| **TBL010** | رؤوس سندات القبض والصرف | CardGuide, MainGuide, BondNumber, BondDate, AccountGuide, CurrencyGuide, Rate, DocumentNumber, Notes, AgentGuide |
| **TBL011** | رؤوس قيود اليومية | CardGuide, EntryNumber, EntryDate, CurrencyGuide, Rate, Notes |
| **TBL012** | تفاصيل قيود اليومية | MainGuide, AccountGuide, CurrencyGuide, Description, Debit, Credit, DebitRate, CreditRate |
| **TBL016** | العملاء/الموردون (للعميل في رأس السند) | CardGuide, AgentName, CardNumber |
| **TBL038** | تفاصيل سندات القبض والصرف | MainGuide, AccountGuide, CurrencyGuide, DebitRate, CreditRate, Notes |

## مسار البيانات

### سند قبض (RECP)
- **TBL010**: رأس السند — MainGuide = نوع قبض
- **TBL038**: سطور — كل سطر له AccountGuide, CreditRate (مبلغ دائن)

### سند صرف (DISB)
- **TBL010**: رأس السند — MainGuide = نوع صرف
- **TBL038**: سطور — كل سطر له AccountGuide, DebitRate (مبلغ مدين)

### قيد يومية (JRNL)
- **TBL011**: رأس القيد — EntryNumber, EntryDate
- **TBL012**: السطور — مدين/دائن (يجب أن يتوازن الإجمالي)

## استعلامات المراجعة المقترحة

```sql
-- آخر السندات (TBL010)
SELECT TOP 20 t10.*, t9.EntryName
FROM TBL010 t10
LEFT JOIN TBL009 t9 ON t10.MainGuide = t9.CardGuide
ORDER BY t10.BondDate DESC, t10.BondNumber DESC;

-- تفاصيل السندات (TBL038)
SELECT t38.*, t4.AccountName
FROM TBL038 t38
LEFT JOIN TBL004 t4 ON t38.AccountGuide = t4.CardGuide
WHERE t38.MainGuide = 'GUID-السند';

-- قيود اليومية (TBL011 + TBL012)
SELECT t11.*, t12.AccountGuide, t12.Debit, t12.Credit, t4.AccountName
FROM TBL011 t11
JOIN TBL012 t12 ON t11.CardGuide = t12.MainGuide
LEFT JOIN TBL004 t4 ON t12.AccountGuide = t4.CardGuide
ORDER BY t11.EntryDate DESC, t11.EntryNumber DESC;

-- رصيد حساب (مجموع TBL038 حسب الحساب)
SELECT AccountGuide, SUM(DebitRate) AS TotalDebit, SUM(CreditRate) AS TotalCredit
FROM TBL038
GROUP BY AccountGuide;
```

## ملاحظات

- إذا لم تكن TBL011 و TBL012 موجودة، أنشئها وفق هيكل Nuit ERP.
- قراءة الحسابات تتم عبر TBL004 (دليل الحسابات).

# سيناريو النوافذ حسب الهيكل الإداري

تم تطبيق نفس آلية قطاع التدريب على كافة القطاعات: كل مستخدم يرى في القائمة الجانبية فقط روابط سيناريوهه.

---

## من يرى ماذا في القائمة الجانبية

| القطاع | الأدوار التي ترى القطاع | الروابط المعروضة |
|--------|-------------------------|-------------------|
| **التسويق** | Manager, Marketing | Daily Sheet (الورقة اليومية) |
| **المبيعات** | Manager, Sales | Sales Dashboard (لوحة المبيعات) |
| **إدارة الحسابات** | Manager, AccountManager | Define Client, Job Orders, AM Dashboard, Invoices, Campaigns |
| **الترشيح (Allocation)** | Manager, Allocator, AllocationManager, AllocationSpecialist | Matching Center, Manager Dash (للمدير/AllocationManager), Matching |
| **التوظيف (Recruitment)** | Manager, Recruiter, RecruitmentManager | My Dashboard, Workbench, Scheduling, Interviews, Onboarding |
| **التدريب** | Manager, TrainingManager, TrainingHead, TrainingLead, TrainingCoordinator, Trainer | Academy للجميع؛ الحضور (Attendance) لـ Manager و Trainer فقط |
| **المواهب (Talent)** | Manager, Talent, Talent_Recruitment, TA-Training | Conduct Tests |
| **المالية** | Manager, Finance | Finance (الحسابات) |
| **الإدارة** | Manager, Admin | Users |

---

## توجيه الدخول (بعد تسجيل الدخول)

- **AccountManager** → لوحة مدير الحسابات  
- **Allocator / AllocationManager / AllocationSpecialist** → مركز المطابقة  
- **RecruitmentManager** → توزيع المهام  
- **Recruiter** → لوحة التوظيف  
- **Sales** → لوحة المبيعات  
- **Marketing** → الورقة اليومية للتسويق  
- **Finance** → صفحة المالية  
- **TrainingManager / Head / Lead / Coordinator** → الأكاديمية  
- **Trainer** → الحضور  
- **Talent / TA-Training / Talent_Recruitment** → Conduct Tests  
- **Manager / Admin** → لوحة التحكم المركزية (الهيكل الإداري)

---

## ملاحظات

- **Dashboard (الرئيسية):** يظهر للجميع؛ عند الضغط يُوجّه كل مستخدم إلى صفحة قطاعه.
- **Global Search و Logout** يظهران للجميع في أسفل القائمة.
- لا يرى مسؤول التوظيف (Recruiter) روابط الترشيح (Allocation) أو إدارة الحسابات؛ ولا يرى المسكّن (Allocator) روابط Workbench أو Scheduling.
